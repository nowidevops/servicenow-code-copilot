# Code of Conduct

Author: iDevOpsLLC

## Our pledge

This tracker exists so people using [Agentic Copilot](https://ai.nowidevops.com) can report problems and get them fixed. Everyone is welcome here, whatever their experience level, employer, or background.

## Expected behavior

- Be respectful and assume good faith. Someone reporting a "basic" problem is exactly who this tracker is for.
- Critique the software, not the person — whether that's a maintainer or another user.
- Add detail rather than "+1" when you're affected by an existing issue; it speeds up the fix.
- Respect confidentiality: never pressure anyone to share instance details, account emails, client names, or internal data. If a post contains sensitive data, flag it privately rather than quoting it.

## Unacceptable behavior

- Harassment, insults, or discriminatory language of any kind.
- Posting someone else's private, personal, or proprietary information.
- Publicly posting security exploit details — report those privately, see [SECURITY.md](SECURITY.md).
- Spam, off-topic promotion, or repeated demands for a timeline on an open issue.

## Scope

This applies to all activity in this repository: issues, comments, and any related discussion.

## Enforcement

Maintainers may edit, hide, or delete content that violates this policy, and may block repeat offenders. To report a problem, contact iDevOps LLC through [ai.nowidevops.com](https://ai.nowidevops.com) — do not quote sensitive content in a public issue.

Reports are handled discreetly and in good faith.

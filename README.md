# Agentic Copilot — Official Issue Tracker

This is the **official issue tracker** for **[Agentic Copilot](https://ai.nowidevops.com)** — the AI-powered ServiceNow development platform by iDevOps LLC. Report bugs, problems, and feature requests here.

> **This is a support tracker, not a code repository.** Agentic Copilot is commercial, closed-source software. No application source code is published here, and nothing in this repository grants any license to the product or its code.

## What this repository is for

| ✅ Use it for | ❌ Not for |
|---------------|-----------|
| Bugs and errors you hit while using the app | Requests for the app's source code |
| A module that won't load, hangs, or returns nothing | General ServiceNow how-to questions unrelated to the app |
| Wrong or broken AI output from a module | ServiceNow platform defects — those go to [ServiceNow Support](https://support.servicenow.com) |
| Sign-in, account, or credit/billing problems | Security vulnerabilities — report those privately, see [SECURITY.md](SECURITY.md) |
| Feature requests and usability suggestions | Anything containing credentials or customer data |

## How to report

1. **Search [existing issues](../../issues)** first, including closed ones — your problem may already be known or fixed.
2. Open a **[new issue](../../issues/new/choose)** and pick a template:
   - **🐛 Bug Report** — something is broken or behaves wrongly
   - **💡 Feature Request** — something you'd like the app to do
   - **❓ Question / Help** — you're stuck and not sure whether it's a bug
3. Fill in the form. The more precise the steps, the faster it gets fixed.

## ⚠️ Before you post: this repository is public

Everything you post here is world-readable and indexed by search engines. **Never include:**

- ❌ Passwords, API keys, or tokens — including any key you pasted into the app
- ❌ Your ServiceNow instance URL (write `<instance>.service-now.com` instead)
- ❌ Real `sys_id` values, ticket numbers, or customer/employee records
- ❌ Proprietary code belonging to your employer or client
- ❌ Screenshots showing any of the above — crop and redact first

You do **not** need to post your account email. If we need it to look up your account, we'll ask you to send it privately.

If you accidentally post a credential, **rotate it immediately** — deleting the comment is not enough. See [SECURITY.md](SECURITY.md).

## Response expectations

This tracker is monitored by the iDevOps LLC team. Issues are triaged and labeled by area and severity. Response times are best-effort — this is a community-facing tracker, not a contracted SLA. Production-critical problems for paid plans should also be raised through your normal support channel at [ai.nowidevops.com](https://ai.nowidevops.com).

## Contributing

Contributions here take the form of **well-written issue reports** — see [CONTRIBUTING.md](CONTRIBUTING.md). Pull requests are not accepted, since this repository contains no application code.
